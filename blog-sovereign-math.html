01 // THE VOLATILITY ENGINE: ROUGH BERGOMI & CGMY

Why Flat Volatility is Cooked

Standard simulators model volatility as a smooth, slowly-varying process — maybe a Heston stochastic vol or a simple GARCH. Real volatility is rough. Empirical studies (Gatheral, Jaisson, Rosenbaum 2018) show that log-volatility behaves like fractional Brownian motion (fBM) with Hurst parameter \(H \approx 0.1\), meaning it has much more jagged, irregular paths than standard Brownian motion (\(H = 0.5\)).

Fractional Brownian Motion

An fBM \(W^H_t\) is a Gaussian process with covariance:

$$\text{Cov}(W^H_s, W^H_t) = \frac{1}{2}\left(|s|^{2H} + |t|^{2H} - |t-s|^{2H}\right)$$

When \(H < 0.5\), the process is anti-persistent — increments are negatively correlated, creating the rough, jagged behavior observed in real vol surfaces. The problem: fBM is not a semimartingale when \(H \neq 0.5\), which breaks Itô calculus and makes simulation expensive.

Markovian Multi-Factor Approximation

Simulating true fBM requires \(O(N^2)\) operations (the entire history matters at each step). SOVEREIGN uses a Markovian multi-factor approximation: we decompose the fractional kernel \(K_H(t) = c_H t^{H-1/2}\) into a weighted sum of exponentials:

$$K_H(t) \approx \sum_{j=1}^{J} w_j e^{-\lambda_j t}$$

Each factor \(j\) evolves as a standard OU process, giving us \(O(J \cdot N)\) simulation cost instead of \(O(N^2)\). We use \(J = 8\) factors, calibrated via least-squares fitting on the kernel.

The Rough Bergomi Variance

The stochastic variance under Rough Bergomi is:

$$v_t = \xi_0 \exp\!\left(\eta \widehat{W}^H_t - \frac{1}{2}\eta^2 V(t)\right)$$

where \(\xi_0\) is the forward variance curve, \(\eta\) controls vol-of-vol, \(\widehat{W}^H_t\) is the Volterra-type fBM driving the log-variance, and \(V(t) = \mathbb{E}[(\widehat{W}^H_t)^2]\) is the analytical martingale compensator. That compensator is critical — without it, the variance process drifts and introduces fake arbitrage into the simulation.

CGMY Lévy Jumps

Gaussian diffusion alone can't produce the fat tails observed in real returns. We inject extreme market shocks using CGMY Lévy jumps — a pure-jump process (no diffusion component) with characteristic function:

$$\phi_{\text{CGMY}}(u) = \exp\!\left(C \Gamma(-Y)\left[(M-iu)^Y - M^Y + (G+iu)^Y - G^Y\right]\right)$$

Parameters: \(C\) controls activity (jump frequency), \(G\) and \(M\) control the decay of positive/negative jumps (asymmetry), and \(Y \in [0,2)\) controls the fine structure — higher \(Y\) means more small jumps (infinite activity when \(Y \geq 1\)).

CIR Subordinator — Crisis Time Acceleration

The CGMY process runs on a CIR subordinator, which stretches operational time during crises. The subordinator \(\tau(t)\) is the integrated CIR process:

$$d\lambda_t = \kappa(\bar{\lambda} - \lambda_t)\,dt + \sigma_\lambda \sqrt{\lambda_t}\,dW_t, \qquad \tau(t) = \int_0^t \lambda_s\,ds$$

When volatility spikes, \(\lambda_t\) increases, accelerating the subordinated time \(\tau(t)\). The CGMY process evaluated at \(\tau(t)\) generates more jumps during stress periods — exactly matching the empirical observation that jump intensity clusters during crises.

02 // ORDER FLOW: HAWKES PROCESSES & OGATA THINNING

Why Poisson is Not Enough

Real order flow exhibits self-excitation: a trade arriving makes more trades likely in the near future (herding, momentum ignition, algo reactions). A Poisson process has constant intensity — it can't model this clustering. Hawkes processes can.

5D Multivariate Hawkes

SOVEREIGN models 5 event types per asset: market buys, market sells, limit buy submissions, limit sell submissions, and cancellations. The conditional intensity for type \(d\) is:

$$\lambda_d(t) = \mu_d + \sum_{d'=1}^{5} \sum_{t_k^{d'} < t} \sum_{m=1}^{M} \alpha_{dd'm}\, \beta_{dd'm}\, e^{-\beta_{dd'm}(t - t_k^{d'})}$$

Each historical event \(t_k^{d'}\) of type \(d'\) excites future events of type \(d\) via a kernel with \(M = 10\) exponential components (capturing fast HFT reactions and slower institutional herding). The branching matrix \(\mathbf{A}\) has entries:

$$A_{dd'} = \sum_{m=1}^{M} \frac{\alpha_{dd'm}}{\beta_{dd'm}}$$

The spectral radius \(\rho(\mathbf{A})\) controls stability: \(\rho < 1\) means the process is stationary (the excitement dies out); \(\rho \geq 1\) means events self-replicate to infinity (blow-up).

Dykstra's Alternating Projections

We enforce \(\rho(\mathbf{A}) \leq 0.95\) using Dykstra's alternating projections algorithm. This iteratively projects the branching matrix onto two constraint sets:

  1. The set of matrices with non-negative entries (physical constraint)
  2. The set of matrices with spectral radius ≤ 0.95 (stability constraint)

This keeps the Hawkes process firmly in the subcritical regime — realistic clustering without divergence.

Ogata Thinning: The Only Way to Simulate

Simulating a multivariate Hawkes process requires Ogata's modified thinning algorithm:

  1. Compute the current intensity upper bound \(\bar{\lambda}(t) = \sum_d \lambda_d(t)\)
  2. Generate candidate arrival time: \(\Delta t \sim \text{Exp}(\bar{\lambda})\)
  3. Accept the event with probability \(\lambda(t + \Delta t) / \bar{\lambda}\); else thin (reject)
  4. If accepted, assign type \(d\) with probability proportional to \(\lambda_d\)

The key challenge: after each accepted event, all 5 intensities jump simultaneously, and the upper bound must be recalculated. We cache the kernel state per-component for O(1) intensity updates using exponential decay properties.

03 // LOB MICROSTRUCTURE

The Limit Order Book (LOB) is packed into Eigen::VectorXi arrays — 20 bid levels and 20 ask levels per asset. Cache locality matters: 50 assets × 40 levels × 4 bytes = 8KB, fitting in L1 cache.

Large orders don't hit the book linearly. We apply a square-root concave price impact model:

$$\text{impact} = \sum_{d=0}^{19} \text{sign}(B_d - A_d)\sqrt{|B_d - A_d|}\,\frac{1}{1 + d}$$

This captures the empirical square-root law of market impact (Bouchaud et al.) — price movement scales as \(\sqrt{\text{volume}}\), not linearly — with a depth-weighting factor \(1/(1+d)\) that discounts deeper levels.

04 // MARKET MAKING & HJB PDEs

Ghost Market Makers

SOVEREIGN runs 5 ghost market makers per asset. Each one continuously posts bid and ask quotes. Their optimal spread is computed by solving a Hamilton-Jacobi-Bellman PDE on a background thread — decoupled from the tick-by-tick simulation loop.

The HJB Equation

The market maker maximizes expected terminal wealth while penalizing inventory risk and Knightian ambiguity (uncertainty about the true model). The value function \(V(t, x, I, \sigma)\) satisfies:

$$\partial_t V + \frac{1}{2}\sigma^2 \partial_{xx}V + \lambda^a(\delta^a)(e^{-\gamma(\delta^a + \Delta x_a)} - 1)\partial_I V$$ $$+ \lambda^b(\delta^b)(e^{-\gamma(\delta^b - \Delta x_b)} - 1)\partial_I V - \theta |\partial_\sigma V| = 0$$

where \(I\) is inventory, \(\delta^{a/b}\) are ask/bid spreads, \(\gamma\) is risk aversion, and \(\theta\) is the ambiguity aversion parameter — the key bridge to the endogenous feedback loop.

Optimal Spread with Ambiguity

The resulting optimal spread formula:

$$\delta^* = \max\!\left(\delta_{\text{HJB}}(I, \sigma) + 2\Psi,\; (\gamma + \theta)\frac{\sigma^2 |I|}{2} + 2\Psi\right)$$

where \(\Psi\) is the asset's ruin probability from the Gerber-Shiu layer. When \(\theta\) increases (market maker becomes more uncertain about the model), spreads widen. When \(\Psi\) increases (bankruptcy risk rises), spreads widen further. Both effects drain liquidity.

05 // GERBER-SHIU RUIN THEORY

To prove penny stocks are fragile, we track each market maker's bankruptcy probability using Gerber-Shiu actuarial ruin theory. The surplus process follows a compound Cramér-Lundberg model:

$$U(t) = u + ct - \sum_{i=1}^{N(t)} X_i$$

where \(u\) is initial capital, \(c\) is premium rate, and \(X_i\) are claim sizes. The Gerber-Shiu expected discounted penalty function satisfies an integro-differential equation (IDE):

$$c\,\Phi'(u) = (\lambda + \delta)\Phi(u) - \lambda \int_0^u \Phi(u-x)f(x)\,dx - \lambda \int_u^\infty w(u,x-u)f(x)\,dx$$

We solve this via Picard iteration — iterating the integral equation until convergence. The output \(\Psi_i\) for each asset feeds directly into the market maker spread formula.

06 // CORRELATION TOPOLOGY

With 50 assets, pairwise correlations form a 50×50 matrix that needs cleaning. We apply Random Matrix Theory (RMT) — eigenvalues below the Marchenko-Pastur bound are noise and get clipped.

From the cleaned correlation matrix, we extract:

  • Minimum Spanning Tree (MST) — the backbone of cross-asset relationships
  • Planar Maximally Filtered Graph (PMFG) — richer than MST, preserving genus-0 topology
  • Laplacian contagion operator — shocks propagate through the network via \(\mathbf{L} = \mathbf{D} - \mathbf{W}\), modeling how a crash in one asset spreads to connected assets

07 // PERSISTENT HOMOLOGY & THE TOPOLOGICAL RISK INDEX

TDA: Topological Data Analysis

We run Vietoris-Rips complexes on the background thread to map cross-asset correlations into topological features. As the filtration parameter \(\epsilon\) increases, simplices appear and disappear — creating birth-death pairs that form a persistence diagram.

Topological Risk Index (TRI)

The TRI aggregates the persistence diagram into a single scalar:

$$\text{TRI}(t) = \sum_{(b_i, d_i) \in \text{PD}_1} (d_i - b_i)^2$$

This sums the squared lifetimes of all 1-dimensional homological features (loops in the correlation structure). When correlations tighten (crisis clustering), loops persist longer, and TRI spikes.

Wasserstein-2 Stability

We track changes in the persistence diagram over time using the Wasserstein-2 distance:

$$W_2(\text{PD}_{t-1}, \text{PD}_t) = \left(\inf_\gamma \sum_{(p,q) \in \gamma} \|p - q\|^2\right)^{1/2}$$

Rapid increases in \(W_2\) signal topological regime changes — the correlation structure itself is mutating.

08 // THE ENDOGENOUS FEEDBACK LOOP

This is the ultimate flex. Two independent feedback paths close the system into a self-crashing engine:

Path 1: TRI → θ (Topology → Ambiguity)

When TRI spikes, the market makers' ambiguity aversion \(\theta\) automatically surges:

$$\theta(t) = \theta_0 \exp\!\left(\alpha \cdot \text{TRI}(t)\right)$$

Higher \(\theta\) → wider spreads → less liquidity → prices become more volatile → correlations tighten → TRI increases further. Positive feedback loop.

Path 2: Ψ → Hawkes (Ruin → Order Flow)

When an asset's ruin probability \(\Psi_i\) crosses 0.5, Hawkes baseline intensity is boosted:

$$\text{mod}_i = 1 + 0.5 \cdot \max(\Psi_i - 0.5,\; 0), \quad \text{mod}_i \in [0.5,\; 5.0]$$

More intensity → more trades → more impact → more price movement → higher ruin probability. Second positive feedback loop.

Why This Matters

These two paths do not share a channel. Path 1 operates through the topology of correlations. Path 2 operates through actuarial ruin of individual assets. Crisis is self-generated across both paths simultaneously — no exogenous shock injected anywhere.

The result: flash crashes emerge organically from the interaction of market makers, order flow, and network topology. This is what makes SOVEREIGN fundamentally different from every other financial simulator.

"The market doesn't need an external shock to crash. It just needs its own participants to become uncertain enough, at the same time, about the same things. SOVEREIGN proves this computationally."
